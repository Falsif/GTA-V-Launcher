# GTA V Launcher

Неофициальный лаунчер для **GTA V Legacy** и **GTA V Enhanced** на Windows 10/11.
Tauri 2 + React + TypeScript, интерфейс на русском, без рекламы и платных API.

> Не связан с Rockstar Games и Take-Two Interactive. Игра запускается только через
> официальные клиенты: лаунчер не обходит DRM, лицензию, вход в аккаунт и античит
> и не работает с GTA Online.

## Что умеет

| Раздел | Что работает |
|---|---|
| **Главная** | Выбор Legacy/Enhanced, статус установки, версия из `GTA5.exe`, время игры, последний запуск, число запусков, новости Steam (с офлайн-кэшем), кнопки «Играть», «Найти GTA V», «Проверить файлы», «Папка игры» |
| **Поиск игры** | Steam (реестр + `libraryfolders.vdf` + `appmanifest_271590/3240220.acf`), Epic Games (манифесты `*.item`), Rockstar Games Launcher (реестр), ручной выбор папки. Проверка нужных файлов |
| **Запуск** | Steam → `steam://rungameid/…`, Epic → `com.epicgames.launcher://apps/…?action=launch`, Rockstar → `PlayGTAV.exe`. Перед запуском — предупреждение, если в папке игры есть моды |
| **Время игры** | Фоновый поток раз в 3 с ищет процесс `GTA5.exe` / `GTA5_Enhanced.exe` и считает время (в том числе в трее) |
| **Моды** | Установка из .zip, папки или файла; включение/отключение; удаление; резервные копии заменяемых файлов; конфликты между модами; категории, поиск, сортировка; название/версия/описание; список модов, поставленных вручную; проверки совместимости (ASI Loader, ScriptHookV, SHVDN, OpenIV, Enhanced) |
| **Настройки игры** | Редактор `Документы\Rockstar Games\<GTA V \| GTAV Enhanced>\settings.xml`: разрешение, режим экрана, VSync, текстуры, тени и т.д. Меняются **только** параметры, которые уже есть в файле. Профили настроек, `commandline.txt`, инструкция по ограничению FPS |
| **Профили** | Локальные профили: имя, аватар (эмодзи или картинка), версия игры, тема, набор модов, своя статистика |
| **Инструменты** | Проверка целостности через клиент, резервные копии конфигурации, быстрый доступ к папкам, список DLC-пакетов и дополнений в `mods`, скриншот (кнопка или **Ctrl+Alt+S** в игре) |
| **Лаунчер** | 6 тем, свой фон с затемнением, сворачивание в трей, сворачивание при запуске, проверка обновлений через GitHub Releases, «меньше анимаций» для слабых ПК |

Все настройки сохраняются автоматически в `%APPDATA%\com.lunexa.gtavlauncher\`.

## Сборка установщика .exe

### Способ 1 — через GitHub (проще всего, ничего не нужно ставить)

1. Создайте репозиторий на GitHub (например, `GTA-V-Launcher`) и загрузите туда все файлы проекта.
2. Откройте вкладку **Actions** → **Сборка установщика Windows** → **Run workflow**.
3. Через ~10–15 минут в результатах сборки появится архив **GTA-V-Launcher-setup** с файлом
   `GTA V Launcher_1.0.0_x64-setup.exe`.

Чтобы выпустить релиз (с ним работает «Проверить обновления»):

```bash
git tag v1.0.0
git push --tags
```

Установщик появится во вкладке **Releases**. В настройках лаунчера укажите свой
репозиторий в формате `владелец/репозиторий` (по умолчанию `Falsif/GTA-V-Launcher`).

### Способ 2 — на своём компьютере с Windows

Нужно один раз установить:

1. **Node.js 20+** — https://nodejs.org
2. **Rust** — https://rustup.rs (вариант по умолчанию)
3. **Microsoft C++ Build Tools** — https://visualstudio.microsoft.com/visual-cpp-build-tools/
   (отметить «Разработка классических приложений на C++»)
4. WebView2 уже есть в Windows 10/11.

Затем в папке проекта:

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # установщик → src-tauri\target\release\bundle\nsis\
```

Установщик: ставит программу для текущего пользователя, создаёт ярлык на рабочем столе
и в меню «Пуск», корректно удаляется через «Приложения и возможности».

## Как работают моды

- Файлы мода хранятся в `%APPDATA%\com.lunexa.gtavlauncher\mods\<id>\`.
- **Включить** — копирует файлы в папку игры. Если файл игры заменяется, оригинал
  сначала сохраняется в `backups\`.
- **Отключить** — удаляет файлы мода и возвращает оригиналы.
- Если два мода пишут один файл, лаунчер покажет конфликт и предложит отключить другой мод.
- Лаунчер не ставит моды, которые заменяют `GTA5.exe`/`PlayGTAV.exe` или оригинальные
  `.rpf` вне папки `mods`. Пакеты `.oiv` нужно ставить через OpenIV.
- Моды, поставленные вручную, только показываются: лаунчер их не трогает.

Автор мода может положить в корень .zip файл `mod.json` — поля подставятся сами:

```json
{ "name": "Мой мод", "version": "1.0", "description": "Что делает мод",
  "category": "scripts", "target": "scripts" }
```

Категории: `vehicles`, `graphics`, `characters`, `maps`, `scripts`, `gameplay`, `other`.

## Ограничения (честно)

- **Время игры** считается, только пока лаунчер открыт или свёрнут в трей.
- **Ограничения FPS** нет в `settings.xml`, поэтому лаунчер показывает инструкцию, а не
  фиктивный ползунок.
- **Скриншот** в эксклюзивном полноэкранном режиме может получиться чёрным — используйте
  «Окно без рамки» или F12 в Steam.
- **Проверка целостности** в Rockstar Games Launcher и иногда в Epic запускается вручную —
  лаунчер откроет клиент и подскажет, куда нажать.
- Если игра стоит в `C:\Program Files`, для установки модов лаунчер может понадобиться
  запустить от имени администратора.
- Обложка на главной загружается из магазина Steam; без интернета показывается градиент.
